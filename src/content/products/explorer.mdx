Glyph Explorer shows public Qubic data in a form you can read. It covers network health, ticks, transactions, identities, tokens, and contracts, and it presents that data without raw RPC responses.

The explorer is a hosted app, so a lookup does not require a local index or a running Qubic client. Open the site, search for an identity or a transaction, and follow the links between records.

An identity page collects the balances and activity for one address. A transaction page shows the transaction and the tick it belongs to. Token and contract pages connect the visible state to the contract metadata that generated it.

The tick view is useful when you need to check whether the network is moving before you investigate a specific transaction. If the latest ticks look healthy and your transaction is not there, the problem is more likely in the transaction path than in the network as a whole.

## Link to a record

The explorer routes are predictable, so an app can link someone straight to an identity, transaction, tick, or contract:

```ts
const explorer = "https://explorer.glyphq.org";

const accountUrl = (identity: string) => `${explorer}/accounts/${identity}`;
const transactionUrl = (hash: string) => `${explorer}/transactions/${hash}`;
const tickUrl = (tick: number) => `${explorer}/ticks/${tick}`;
const contractUrl = (name: string) => `${explorer}/contracts/${name.toLowerCase()}`;
```

## For development

The explorer is a quick way to inspect what a contract call or transfer did before writing a query against an index. For repeated reads, streams, or historical analysis, use [Glyph API](/products/api), which is the self-hosted data service in the same stack.
